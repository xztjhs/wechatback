## 2. P2 消息归一

| 项目 | 结果 |
|---|---|
| 类型解析 | `local_type` 是位打包：`base_type = local_type & 0xFFFFFFFF`，`subtype = local_type >> 32` |
| 图片映射 | `packed_info_data` 末尾 32 位 hex = 本地 `.dat` 文件名 |
| 视频映射 | XML `md5`/`originsourcemd5` → `video_hardlink_info_v4`；缺失时按 `(月份, length)` 匹配 |
| 文件映射 | XML `md5` → `file_hardlink_info_v4`；兜底 `msg\file\<月份>\<title>` |
| 群聊发送者 | 每个 `message_N.db` 用自己的 `Name2Id.rowid` 解析 |
| 压缩 | `WCDB_CT_message_content=4` 用 zstd 解压 |

## 5. 已知限制

1. 视频/文件只能导出微信本地已下载的副本；未下载的只能保留消息占位。
2. WXGF 动图当前只取首帧为 PNG；后续可加 GIF 多帧。
3. 语音不在导出范围，正文显示 `[语音 Ns]`。
4. 微信升级可能改变 `.dat`/数据库格式；升级后先跑 `doctor` + 20 条样本。
5. NAS 是 SMB；全量 36 万文件写入耗时较长，建议一次性跑完，增量再按需运行。
